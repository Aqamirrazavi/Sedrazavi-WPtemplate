## 🎯 هدف بنیادین پروژه: «من بیشتر دنبال چه چیزی هستم؟»

این پروژه صرفاً یک قالب تک‌منظوره یا یک بسته متمرکز بر یک صنف خاص نیست؛ هدف بنیادین آن ساخت یک **موتور تولید، شخصی‌سازی، انتقال و مدیریت سریع قابلیت‌های وردپرسی و المنتوری (Rapid Site Builder & Capability Engine)** است. 

به زبان ساده، این سامانه ابزاری است که به شما امکان می‌دهد ظرف چند دقیقه روی **هر سایت خام وردپرسی**، بدون نیاز به طراحی از صفر و بدون نیاز به کدنویسی، یک سایت فوق‌حرفه‌ای و آماده فروش ایجاد کنید:

### ۴ ستون اصلی نیاز و چشم‌انداز کاربر:
1. **بانک جامع ویجت‌های لندینگ‌پیج و فروش (Landing & Conversion Widgets Vault):**
   - ویجت‌های فوق‌حرفه‌ای با **نوار تنظیمات کناری کامل ۳-تب بومی المنتور** (`Content`، `Style`، `Advanced`).
   - تنظیمات فونت، فاصله‌ها (Padding/Margin)، رنگ‌بندی، گرادینت، سایه‌ها، Repeater، و سوئیچرها دقیقاً درون المنتور بدون نیاز به داشبورد خارجی.
   - ویجت‌های نرخ تبدیل: جدول قیمت‌گذاری هوشمند، شمارنده روانی FOMO، اسلایدر قبل و بعد، شمارنده آماری، باکس‌های اقدام شناور (Floating CTA) و آکاردئون هوشمند FAQ با اسکیما.

2. **بانک تمپلیت‌های ویرایش‌پذیر کانتینری و تم‌بیلدر (Theme Builder & Container Templates):**
   - بیش از ۲۳ تمپلیت آماده بر پایه Flexbox و Container رسمی المنتور.
   - شامل صفحات لندینگ کامل، سربرگ چسبان (Header)، پابرگ پیشرفته (Footer)، برگه تکی مقالات (Single Post)، برگه آرشیو و وبلاگ (Archive)، و صفحه هوشمند ۴۰۴.
   - **ویرایش‌پذیری واقعی:** پس از درون‌ریزی، تمام کانتینرها، متن‌ها و ویجت‌ها مستقیماً در ویرایشگر درگ‌اند‌دراپ المنتور باز و قابل سفارشی‌سازی هستند.
   - **سازگاری هوشمند با نسخه رایگان و پرو:** در غیاب المنتور پرو، به جای شکست یا قفل‌شدگی، فال‌بک تمیز اجرا می‌شود.

3. **معماری بسته‌های ماژولار و مستقل قابلیت‌ها (Modular Portable Capability Architecture):**
   - هر قابلیت (مانند قیمت‌گذاری، شمارنده، نمونه‌کار یا رزرو) به صورت یک واحد خودکفا (`manifest.json`) بسته‌بندی شده است.
   - امکان استخراج هر قابلیت به صورت یک پکیج زیپ مستقل و نصب آن بر روی هر سایت وردپرسی دیگر بدون نیاز به قالب اصلی SedRazavi.

4. **عملکرد خالص و بدون بلوغ جاوااسکریپتی (Zero-CDN & Clean HTML/CSS/PHP):**
   - فرانت‌اند عمومی سایت **کاملاً عاری از بار سنگین فریم‌ورک‌های SPA (مثل React)** است.
   - صددرصد دارایی‌ها (آیکون‌های SVG، فونت‌های محلی، استایل‌ها) بدون اتصال به CDNهای خارجی و به شکل محلی و سبک رندر می‌شوند تا بالاترین امتیاز Core Web Vitals و LCP حاصل شود.

## 🏛️ معماری ۶ لایه سیستم (Decoupled 6-Layer Architecture)

```
┌────────────────────────────────────────────────────────────────────────┐
│ لایه ۱: رابط‌های کاربری (UI) - ویجت‌های المنتور با سایدبار کامل + گوتنبرگ│
├────────────────────────────────────────────────────────────────────────┤
│ لایه ۲: قراردادهای ارتباطی (Contracts) - REST API + Nonce + Permissions│
├────────────────────────────────────────────────────────────────────────┤
│ لایه ۳: سرویس‌های بک‌اند (Services) - ایمپورتر تمپلیت، کوئری و اتوماسیون│
├────────────────────────────────────────────────────────────────────────┤
│ لایه ۴: مدل داده و رویدادها (Data/Events) - CPTs، تاکسونومی‌ها و ایونت‌باس│
├────────────────────────────────────────────────────────────────────────┤
│ لایه ۵: مدیریت و نظارت (Admin) - Capability Registry + Package Manager │
├────────────────────────────────────────────────────────────────────────┤
│ لایه ۶: زیرساخت وردپرس (Infrastructure) - Database + Caching + PHP 8.x │
└────────────────────────────────────────────────────────────────────────┘
```

## 📦 بسته‌های استاندارد خروجی (Production Packages)

پایپ‌لاین پکیجینگ پروژه بسته‌های استاندارد زیر را به طور مستقل در ریشه و پوشه `public/` تولید می‌کند:

| نام بسته | حجم تقریبی | شرح و محتویات |
| :--- | :--- | :--- |
| `elementor-addon-suite.zip` | ~۰.۲ مگابایت | افزونه مادر المنتور شامل کلیه ویجت‌های فرود، موتور ایمپورت ۲۳+ تمپلیت، رجیستری قابلیت‌ها و پکیج‌منیجر |
| `sedrazavi-theme.zip` | ~۳.۰ مگابایت | پوسته سبک و فوق‌سریع وردپرس با پشتیبانی کامل از استانداردهای FSE و گوتنبرگ (تفکیک‌شده از چایلدتم‌ها) |
| `sedrazavi-addons.zip` | ~۰.۰۳ مگابایت | افزونه قابلیت‌های اختصاصی و CPTهای تفکیک‌شده محرمانه و عمومی |
| `sedrazavi-companion.zip` | ~۰.۱۲ مگابایت | افزونه کمکی شورت‌کدها، بلوک‌های صنعتی و ابزارهای توسعه |
| `sedrazavi-complete-ecosystem.zip` | ~۱۴ مگابایت | اکوسیستم کامل شامل تم مادر، ۸ پوسته فرزند، افزونه‌ها و دارایی‌های ۶۶گانه |

## 🛠️ دستورات تست و اعتبارسنجی

تمامی ابعاد معماری، امنیت، بلوک‌های گوتنبرگ، رجیستری قابلیت‌ها و پکیج‌ها توسط تست‌های خودکار اعتبارسنجی می‌شوند:
```bash
# اجرای تمامی ۱۵۱+ آزمون خودکار معماری و امنیت
npm run test:all

# تست اختصاصی معماری ماژولار و پورتابل (MPCA)
npm run test:mpca

# اعتبارسنجی تایپ‌اسکریپت و بیلد
npm run lint
npm run build

# ساخت بسته‌های فشرده زیپ
node scripts/pack-theme-zips.cjs
```
