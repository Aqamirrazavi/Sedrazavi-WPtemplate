# پوسته حقوقی و وکالت SedRazavi (SedRazavi Law Firm WordPress Theme)

پوسته اختصاصی، فوق‌پیشرفته و هیبریدی **SedRazavi** طراحی‌شده برای دفاتر وکالت، مشاوران حقوقی و مراکز داوری. این پروژه شامل دو بخش یکپارچه است:
۱. **پوسته استاندارد و قابل نصب وردپرس** در دایرکتوری `/wordpress-theme` (آماده بسته‌بندی ZIP و نصب در هر وردپرس ۶.۰+)
۲. **اپلیکیشن تعاملی و ابزار مدیریت React 19 + Vite** در `/src` جهت توسعه، پیش‌نمایش و تولید خودکار باندل‌های کلاینت

---

## 📁 ساختار واقعی فایل‌های پوسته وردپرس (`/wordpress-theme`)

تمام فایل‌های استاندارد یک تم کامل وردپرس در پوشه `wordpress-theme/` مستقر هستند:

| مسیر فایل | نقش و کاربرد |
|---|---|
| `wordpress-theme/style.css` | هدر رسمی پوسته وردپرس (Theme Name, Version, Requires PHP 8.0+, Text Domain) |
| `wordpress-theme/functions.php` | بارگذاری استایل‌ها، انکیو اسکریپت‌های باندل، سیستم ثبت نوبت و استعلام پرونده با Nonce و Rate Limiting |
| `wordpress-theme/header.php` | سئوی پویا (SSR SEO)، اپن‌گراف، کارت توییتر، تگ‌های مکان محلی (ونک، تهران) و اسکیما LegalService و Attorney |
| `wordpress-theme/footer.php` | هوک استاندارد `wp_footer()` و خاتمه ساختار HTML |
| `wordpress-theme/index.php` | محتوای کامل اولیه رندرشده توسط سرور (SSR) به همراه روت هیدراتاسیون ری‌اکت |
| `wordpress-theme/page.php` | قالب استاندارد برگه‌ها با پشتیبانی از المنتور و شورت‌کدها |
| `wordpress-theme/single.php` | قالب اختصاصی مقالات و پرونده‌های حقوقی |
| `wordpress-theme/screenshot.png` | تصویر پیش‌نمایش پوسته در بخش نمایش > پوسته‌های پیشخوان وردپرس |
| `wordpress-theme/inc/react-shortcodes.php` | ۱۵ شورت‌کد اختصاصی PHP برای هیدراتاسیون ماژولار کامپوننت‌های تعاملی |
| `wordpress-theme/assets/dist/` | باندل‌های کامپایل‌شده JS و CSS حاصل از `npm run build` |
| `wordpress-theme/assets/js/sedrazavi-react-mount.js` | موتور شناسایی DOM و مانت خودکار کامپوننت‌های React در هر کجای وردپرس و المنتور |

## 🔒 امنیت، اعتبارسنجی و سئو در سمت سرور (PHP)

- **اعتبارسنجی دوطرفه (Full Sanitization)**: تمام فرم‌ها در سمت سرور PHP توسط `sanitize_text_field` و عبارات باقاعده اعتبارسنجی می‌شوند.
- **بررسی توکن امنیتی (Nonce Verification)**: همه تراکنش‌های AJAX با `check_ajax_referer('sedrazavi_security_nonce', 'nonce')` محافظت می‌شوند.
- **محدودسازی نرخ درخواست (Rate Limiting)**: درخواست‌های ثبت نوبت و استعلام وضعیت پرونده با ترنزینت‌های وردپرس (`set_transient`) بر اساس IP کاربر سقف‌گذاری شده‌اند (۵ درخواست نوبت در ۱۰ دقیقه و ۱۵ استعلام در ۵ دقیقه).
- **سئوی مستقل از جاوااسکریپت (SSR Content)**: در زمان `Ctrl+U` یا خزش ربات‌های جستجو، کلیه عناوین، اطلاعات تماس ونک، پروانه وکالت و خلاصه‌ی خدمات در HTML اولیه وجود دارند.
- **تصاویر و هویت بصری معتبر**: متادیتای Open Graph و Schema.org منحصراً از دارایی‌های رسمی دفتر وکالت (`/screenshot.png` و لاگوی سفارشی) استفاده می‌کنند و هیچ عکس استوک خارجی در داده‌ساختاریافته قرار ندارد.

## ⚙️ پایپ‌لاین CI/CD

پروژه مجهز به گیت‌هاب اکشن رسمی در مسیر `.github/workflows/build-and-release.yml` است که:
۱. فرآیند تایپ‌چک و ساخت باندل فرانت‌اند (`npm run build`) را اجرا می‌کند.
۲. صحت ساختار پوشه `wordpress-theme/` را اعتبارسنجی می‌کند.
۳. پکیج آماده نصب `sedrazavi-theme.zip` را جهت استقرار تولید می‌کند.

---

## 🚀 روش ساخت و دریافت بسته ZIP پوسته

جهت کامپایل باندل کلاینت و کپی فایل‌ها به پوشه تم:
```bash
npm run build
```
جهت ایجاد فایل زیپ قابل بارگذاری در پیشخوان وردپرس:
```bash
cd wordpress-theme && zip -r ../sedrazavi-theme.zip ./* -x ".*"
```
همچنین داخل نرم‌افزار، در تب **کد پوسته وردپرس** دکمه دانلود خودکار پکیج کامل زیپ تم تعبیه شده است.
