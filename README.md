## 🎯 هدف بنیادین پروژه: «من بیشتر دنبال چه چیزی هستم؟»

این پروژه صرفاً یک قالب تک‌منظوره یا یک بسته متمرکز بر یک صنف خاص نیست؛ هدف بنیادین آن ساخت یک **موتور تولید، شخصی‌سازی، انتقال و مدیریت سریع قابلیت‌های وردپرسی و المنتوری (Rapid Site Builder & Capability Engine)** است. 

به زبان ساده، این سامانه ابزاری است که به شما امکان می‌دهد ظرف چند دقیقه روی **هر سایت خام وردپرسی**، بدون نیاز به طراحی از صفر و بدون نیاز به کدنویسی، یک سایت فوق‌حرفه‌ای و آماده فروش ایجاد کنید:

### ۴ ستون اصلی نیاز و چشم‌انداز کاربر:
1. **بانک جامع ویجت‌های لندینگ‌پیج و فروش (۳۱ ویجت المنتوری بومی):**
   - ویجت‌های فوق‌حرفه‌ای با **نوار تنظیمات کناری کامل ۳-تب بومی المنتور** (`Content`، `Style`، `Advanced`).
   - تنظیمات فونت، فاصله‌ها (Padding/Margin)، رنگ‌بندی، گرادینت، سایه‌ها، Repeater، و سوئیچرها دقیقاً درون المنتور بدون نیاز به داشبورد خارجی.
   - ویجت‌های نرخ تبدیل: جدول قیمت‌گذاری هوشمند، شمارنده روانی FOMO، اسلایدر قبل و بعد، شمارنده آماری، باکس‌های اقدام شناور (Floating CTA) و آکاردئون هوشمند FAQ با اسکیما.

2. **بانک تمپلیت‌های ویرایش‌پذیر کانتینری و تم‌بیلدر (۳۳ قالب آماده استاندارد):**
   - ۳۳ تمپلیت واقعی JSON مبتنی بر Flexbox و Container رسمی المنتور (شامل ۳۰ قالب کانتینری/تم‌بیلدر و ۳ پاپ‌آپ تعاملی).
   - شامل صفحات لندینگ کامل، سربرگ چسبان (Header)، پابرگ پیشرفته (Footer)، برگه تکی مقالات (Single Post)، برگه آرشیو و وبلاگ (Archive)، تک‌محصول فروشگاهی و صفحه هوشمند ۴۰۴.
   - **ویرایش‌پذیری واقعی:** پس از درون‌ریزی، تمام کانتینرها، متن‌ها و ویجت‌ها مستقیماً در ویرایشگر درگ‌اند‌دراپ المنتور باز و قابل سفارشی‌سازی هستند.
   - **پل ارتباطی هوشمند با نسخه رایگان و پرو (Theme Builder Bridge):** در غیاب المنتور پرو، به جای شکست یا قفل‌شدگی، فال‌بک تمیز با تزریق خودکار هدر، فوتر، تک‌پست و ۴۰۴ اجرا می‌شود.

3. **استودیوی ساخت جعبه‌ابزار سفارشی و قابل حمل (Custom Project Kit Studio - ADR 009):**
   - امکان انتخاب گزینشی و چک‌باکسی هر یک از ۳۱ ویجت، ۳۳ قالب، ۷ بلوک گوتنبرگ و اسکیماهای پست‌تایپ عمومی برای هر پروژه دلخواه مشتری (شرکتی، کلینیک، فروشگاه، آموزشی، حقوقی، آژانس).
   - کامپایل درجا و خروجی ۱-کلیکی بسته مستقل (Standalone Plugin ZIP) با امضای SHA-256 فایل‌به‌فایل (`file_checksums`)، الزام شرطی Elementor و بارگذاری خودکار الگوها در کتابخانه المنتور سایت مقصد.

4. **معماری Zero-CDN و بارگذاری انتخابی ری‌اکت (Selective React):**
   - صفحات عمومی سایت، برگه‌های المنتوری و بلوک‌های گوتنبرگ **بدون بارگذاری ری‌اکت (Zero-React Public Frontend)** رندر می‌شوند.
   - باندل React تنها به‌صورت انتخابی و مشروط روی صفحات/شورت‌کدهای تعاملی (`[react_component]`، `[sedrazavi_dashboard]`، `[sedrazavi_client_portal]`، `[sedrazavi_calculator]`، برگه‌های `designer`/`portal` و پیش‌نمایش مجاز `?app_preview`) بارگذاری می‌گردد.
   - صددرصد دارایی‌ها (آیکون‌های ۶۶گانه SVG، فونت‌های محلی و استایل‌ها) بدون وابستگی به CDNهای خارجی و به شکل محلی سرو می‌شوند.

## 🏛️ معماری ۶ لایه سیستم (Decoupled 6-Layer Architecture)

```
┌────────────────────────────────────────────────────────────────────────┐
│ لایه ۱: رابط‌های کاربری (UI) - ویجت‌های المنتور با سایدبار کامل + گوتنبرگ│
├────────────────────────────────────────────────────────────────────────┤
│ لایه ۲: قراردادهای ارتباطی (Contracts) - REST API + Nonce + Permissions│
├────────────────────────────────────────────────────────────────────────┤
│ لایه ۳: سرویس‌های بک‌اند (Services) - ایمپورتر تمپلیت، کوئری و اتوماسیون│
├────────────────────────────────────────────────────────────────────────┤
│ لایه ۴: مدل داده و رویدادها (Data/Events) - CPTs، تاکسونومی‌ها و ایونت‌باس│
├────────────────────────────────────────────────────────────────────────┤
│ لایه ۵: مدیریت و نظارت (Admin) - Capability Registry + Package Manager │
├────────────────────────────────────────────────────────────────────────┤
│ لایه ۶: زیرساخت وردپرس (Infrastructure) - Database + Caching + PHP 8.x │
└────────────────────────────────────────────────────────────────────────┘
```

## 📦 بسته‌های استاندارد خروجی (Production Packages)

پایپ‌لاین پکیجینگ پروژه بسته‌های استاندارد زیر را به‌طور مستقل در پوشه `public/` و ریشه مخزن تولید می‌کند:

| نام بسته | حجم تقریبی بیلد | شرح و محتویات |
| :--- | :--- | :--- |
| `elementor-addon-suite.zip` | ~۰.۶۹ مگابایت | افزونه مادر المنتور شامل ۳۱ ویجت بومی، ۳۳ تمپلیت کانتینری و پاپ‌آپ، ۷ بلوک گوتنبرگ، Package Manager و تم‌بیلدر بریج |
| `sedrazavi-theme.zip` | ~۴.۵ مگابایت | پوسته اصلی سبک و سئو-محور وردپرس با پشتیبانی FSE و گوتنبرگ و اسکریپت‌های تعاملی REST |
| `sedrazavi-addons.zip` | ~۰.۳۶ مگابایت | افزونه قابلیت‌های عمودی حقوقی (پرونده‌ها، نوبت‌دهی، OTP و شورت‌کدهای استعلام متصل به REST API) |
| `sedrazavi-companion.zip` | ~۰.۵۱ مگابایت | افزونه مستقل Frontend Management Cockpit (کنسول مدیریتی سمت افزونه)، دموایمپورتر، LMS و شتاب |
| `sedrazavi-designer-bundle.zip` | ~۱.۴ مگابایت | بسته یکپارچه طراح وردپرس بدون کدنویسی (پوسته مستقل + افزونه `sedrazavi-designer-core.zip`) |
| `sedrazavi-complete-ecosystem.zip` | ~۸.۶ مگابایت | پکیج کامل اکوسیستم شامل پوسته اصلی، ۸ پوسته مستقل (Standalone Themes) و افزونه‌های رسمی |

## 🛠️ دستورات تست و اعتبارسنجی

بررسی‌های Node.js، امنیت ایستای کد، TypeScript، Vite و ساختار بسته‌های ZIP با دستورات زیر اجرا می‌شوند (توجه: آزمون‌های زنده PHP/WordPress/Elementor نیازمند محیط دارای `php` CLI و Docker هستند):
```bash
# اجرای کل سوئیت‌های اعتبارسنجی Node / AST / ZIP
npm run test:all

# تست ممیزی امنیتی P0، واقعی‌بودن اندپوینت‌ها و یکپارچگی بسته‌ها
npm run test:remediation

# تست اختصاصی معماری ماژولار و پورتابل (MPCA)
npm run test:mpca

# همگام‌سازی فایل‌ها، تایپ‌اسکریپت و بیلد تولیدی
npm run sync:all
npm run build
node scripts/pack-theme-zips.cjs
```
